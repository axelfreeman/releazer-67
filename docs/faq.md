# FAQ

## Which API keys do I need?

Only the channels you want to use: GitHub for reading traces, Dev.to for publishing articles, Google Ads for paid campaigns. You can start with none — Releazer drafts everything and you approve before anything goes out.

## Is my code safe?

Releazer reads only the traces you point it at — commits, PRs, diffs. It runs inside your agent and never uploads your code anywhere.

## What if my release is boring?

Releazer triages importance. A boring release accumulates quietly; a meaningful one gets the full launch. It won't force a launch that won't land.

## What does it cost?

The beta is free — key: `RELEAZER-BETA-FREE`. Full pricing ships with releazer.online.

## Who should NOT use it?

- Products that don't ship updates — no releases, no content to market.
- Extremely complex products — the integration cost would outweigh the value.
- Security-restricted code that can't be scanned (for example, core banking services).

Everyone else who ships code: Releazer fits.
