# Example

## The release

A founder ships an update to their job auto-apply service — a product that automatically responds to new job postings for its users.

## What Releazer does

Releazer reads the code and understands how the product *actually* works — then describes it to the user in a way the founder would never have written.

The founder sees the code: a scheduler, a matching loop, a submitter. Releazer sees the story:

> "You stop answering job ads by hand. The product watches new postings, matches them to your profile, and applies for you while you do something else."

Then it ships that story everywhere:

| Channel | Output |
|---------|--------|
| Announcement | A human-language headline the founder didn't have to write |
| Social | A post that explains the feature, not the diff |
| Media | A pitch to outlets that cover job-search and automation tools |
| Training | A short video if the feature changes how users work |
| Knowledge base | The release added to docs, in plain language |

The code stays code. The marketing writes itself from the traces.
